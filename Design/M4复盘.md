## 复盘 4 问

### Q1：角色代价表若扩到 5 个角色：`lookup_multi` 是否够用？要不要抽成"角色×地形"二维表 / JSON？

**结论：保持行式 CSV + `lookup_multi`。**

- 5 角色 × 5 地形 = 25 行，多条件查询（`{role, terrain}` → cost/solid）无压力。
- 事实澄清：CSV **支持**二维表（矩阵式：首行表头地形、首列角色、中间填 cost），但 `gd_config` 是"行式键值"加载（一行一条记录），矩阵 CSV 需要项目侧自写解析器才能读。
- 判断标准：只有当出现"**按角色批量配置**"的需求（如某角色全地形被动系数、免疫某类地形——需要读一整行/一整块）时，才值得换矩阵 CSV 或 JSON 嵌套。
- 策划 Excel 编辑方便优先 → 行式 CSV 最友好（`Design/cost_table.xlsx` 直接导出）。

### Q2：A* 是否只依赖"单格代价查询函数"而非具体角色类型？换角色是否零改寻路？

**结论：是，零改寻路。**

- `PathFinder` 只依赖查询函数契约：`ConfigManager.get_cost(role, terrain)` / `is_solid(role, terrain)`，不认"乌龟/兔子"的具体逻辑。
- 新加"狐狸"角色 = 配置表加一行 + `PathFinder.new(gd, "fox")`，寻路代码一行不改。
- 这是 M0"表驱动"承诺兑现的实证：A* 依赖接口契约而非具体类型。

### Q3：移动速度与地形代价的关系放在逻辑层还是表现层？

**结论：逻辑层管代价/耗时/结算，表现层只管位置插值动画。**

- `delta` 是**真实物理时间**（上一帧到本帧的秒数）：60fps 累加 60×1/60 = 1 秒，120fps 累加 120×1/120 = 1 秒——**与帧率无关**，`elapsed` / `finish_time` 基于 delta 累加，结算精确可复算。
- 放表现层（Tween）的问题不是帧率，而是 Tween 时长是"**意图时间**"，会被暂停、引擎 `time_scale`、编辑器操作干扰；且"快慢"的语义应由代价（逻辑事实）决定，不该由动画时长决定。
- 原则一句话：**逻辑层管"事实"（代价 → 耗时 → 结算），表现层管"呈现"（动画）**。

### Q4：网格数据类和渲染节点是否强绑定？地图从 20×12 扩到 100×60，性能与改动量如何？

**结论：不绑定（单向依赖），扩规模主要动渲染层和 flood_fill，数据层零改动。**

- 架构：`GridData`（RefCounted 纯数据）← `TrackGenerator` 写、`PathFinder` 读、`TerrainRenderer` 读——数据不依赖渲染，渲染持有数据引用（单向）。
- 扩到 100×60（6000 格）：
  - 数据结构 `Dictionary[Vector2i, String]`：**不用改**（哈希查找 O(1)，6000 格无压力）。
  - 生成 `O(n)`：无压力。
  - 渲染：6000 个 `MeshInstance3D` 节点 → 场景树与 draw call 压力大 → 换 **`MultiMeshInstance3D`**（一个节点渲染几千实例，每实例只存 transform）或 **`GridMap`**（Godot 专为网格地图设计，配合 MeshLibrary）。
  - 寻路可达性：`TrackGenerator.flood_fill` 是**递归**，6000 格可能爆栈 → 改**迭代版 BFS**（Array 当队列 + `while` 循环，逻辑完全等价，不占调用栈）。

## 附：魔改 A（顺风/逆风事件）验证记录

- **验证目标**：代价表是否真的"配置驱动、改得起"。
- **实现**：`ConfigManager`（ProjectConfig.gd）加**覆盖层** `cost_override` 字典 + `set_cost_override` / `clear_cost_override`；`get_cost` 优先查覆盖。表 = 原价（永久），覆盖层 = 促销（临时），`clear` 即恢复原价——恢复零成本、多事件可并存。
- **零改动证明**：`Racer` 每进一格才查一次 `get_cost` → 事件临时改查询结果，下一格自动生效，`Racer` / `PathFinder` 一行不改。
- **经验坑 1**（M2 记录延续）：`AStarGrid2D.update()` 会清空全部 point data，只能开头一次，改 weight/solid 后需重建。
- **经验坑 2**（本魔改新踩）：事件地形若从全部地形随机，**大概率命不中角色路径**（路径 90% 是 flat）→ 效果为零。修正：事件地形只从该角色路径上实际存在的地形里选，命中率 100%。
